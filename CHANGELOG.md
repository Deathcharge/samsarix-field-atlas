# Changelog

Notable changes to Samsarix Field Atlas are recorded here. This project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.0.0] - 2026-08-11

### Added

- Local-first deterministic traces for three coordination scenarios and the complete 13-role reference model.
- Guided Scenario Studio authoring plus shared browser and command-line blueprint validation.
- Portable blueprint suites, deterministic baseline comparison, and bounded declared-change review artifacts.
- Draft A2A 1.0 Agent Card, implementation-acceptance, TCK-evidence, and owner-review handoff workflows.
- JSON, SARIF, JUnit, and Markdown projections for CI and human review.
- A bounded optional Node server and a subpath-safe static build published on GitHub Pages.
- Automated cross-platform CI, coverage thresholds, reproducible example fixtures, and publication-drift checks.

### Legal and operations

- Adopted AGPL-3.0-only for the public project, with separately negotiated commercial licensing available from `contact@samsarix.com`.
- Added contributor, conduct, support/security, notice, and trademark guidance for Samsarix LLC stewardship.
- Declared public support and private-reporting contact at `support@samsarix.com`.

### Maintenance

- Updated compatible development tooling while retaining TypeScript 5.9 until the lint toolchain supports TypeScript 7.
- Constrained vulnerable transitive development dependencies to patched releases.
