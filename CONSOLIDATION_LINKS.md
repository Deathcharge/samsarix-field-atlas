# Portfolio context

Samsarix Field Atlas is intentionally independent from any runtime or private Samsarix service.

- [Helix-Collective-Web](https://github.com/Deathcharge/Helix-Collective-Web) is the legacy GitHub repository slug for this standalone, static Samsarix reference simulator.
- [helix-unified](https://github.com/Deathcharge/helix-unified) is a historical pre-rebrand related repository; it is not a runtime dependency or a current product claim here.

The atlas has no runtime dependency on `helix-unified` or any private Samsarix service. Earlier portal, Railway, Zapier, Discord, Notion, storage, and Manus links were removed because this repository neither implements nor verifies those integrations.

Historical ecosystem concepts remain in [CONTEXT.md](CONTEXT.md) as non-normative source material. They are not product commitments or evidence of deployed services.
